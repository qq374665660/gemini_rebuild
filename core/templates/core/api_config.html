使用说明

了解如何配置和使用AI服务

配置步骤

  1. 选择要配置的AI服务类型
  2. 确认服务地址和模型名称
  3. 云端服务输入API密钥，本地模型可留空
  4. 点击"保存配置"按钮
  5. 使用"测试连接"验证配置是否正确
  6. 启用服务开始使用AI分析功能

注意事项

  • API密钥将被安全加密存储
  • 建议定期测试连接以确保服务可用
  • 同一服务类型保存一套模型配置
  • 禁用的服务不会被用于AI分析
  • 只有连接测试通过的配置才会出现在模型选择器中
